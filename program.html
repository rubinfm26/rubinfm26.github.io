Hack-Week Program

Three days of model runs, project work, and merged code

Overview

Schedule at a Glance

The program is structured so that every participant runs an existing SkAI model on real Rubin photometry inside Hyrax on Day 1, and Days 2 and 3 build downstream projects on the shared representation (the SELDON and StarEmbed output for every live alert-stream source, published in Hyrax).

Day 1 — Monday, December 7

Tools and First Light

  • Intro to Hyrax and LINCC Frameworks tools
  • Access to the live alert stream and Data Preview 2 imaging
  • First run of SELDON or StarEmbed on real Rubin photometry
  • Project pitches and team formation

Day 2 — Tuesday, December 8

The Shared Representation

  • Shared representation published in Hyrax
  • Live alert ingestion from the Prompt Products Database (PPDB)
  • Team projects (classification, anomaly search, galaxy mergers, weak lensing)
  • Validation against catalog cross-matches

Day 3 — Wednesday, December 9

Code Review and Presentations

  • Final sprint and simulation-to-real comparisons
  • Code review and merged pull requests
  • Project presentations
  • Community paper outline

Additional Information

Program Notes

Before You Arrive

Preparatory material from the Rubin Data Academy and a plain-language primer on the SkAI models will be sent to participants in advance, so the first day begins with data analysis.

Computing Resources

All computing is supported by an existing NCSA Delta GPU allocation. Account details will be shared with confirmed participants before the hack-week.

Code of Conduct

LINCC Frameworks is an LSST Discovery Alliance program, so all participants are required to abide by the LSST Discovery Alliance Code of Conduct. Reporting procedures will be shared at registration.
