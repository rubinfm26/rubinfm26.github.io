Hack-Week Program

Three days from first model run to merged code

Overview

Schedule at a Glance

Day 1 gets every participant running a SkAI model on real Rubin data. Days 2 and 3 build on the shared latent space.

Day 1 — Wednesday, November 4

Tools and First Light

  • Intro to Hyrax and LINCC Frameworks tools
  • Access to the live alert stream and DP2 imaging
  • Run an existing SkAI model on real Rubin photometry
  • Project pitches and team formation

Day 2 — Thursday, November 5

The Shared Latent Space

  • SELDON and StarEmbed embeddings published in Hyrax
  • Live alert ingestion from the Prompt Products Database
  • Teams build downstream projects
  • Validation against catalog cross-matches

Day 3 — Friday, November 6

Ship It

  • Final sprint and simulation-to-real comparisons
  • Code review and merged pull requests
  • Project presentations
  • Community paper outline

Additional Information

Program Notes

Before You Arrive

Preparatory material from the Rubin Data Academy and a plain-language primer on the SkAI models will be sent to participants in advance, so Day 1 starts with data analysis rather than setup.

Computing Resources

All computing is supported by an existing NCSA Delta GPU allocation. Account details will be shared with confirmed participants before the hack-week.

Code of Conduct

All participants are required to abide by the LINCC Frameworks Code of Conduct. Reporting procedures will be shared at registration.
